# Calculadora em Python

Uma calculadora desenvolvida em Python utilizando a biblioteca **CustomTkinter** para a criação da interface gráfica.

O projeto foi feito com o objetivo de praticar e testar conhecimentos em desenvolvimento de interfaces gráficas, criação de funções e organização de código em Python.

## Tecnologias usadas

- Python
- CustomTkinter

## Objetivos

- Praticar a criação de interfaces gráficas com Python.
- Trabalhar com funções e operações matemáticas.
- Aprender a organizar os componentes de uma interface.
- Explorar os recursos da biblioteca CustomTkinter.

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/Joaor809/calculadora-python.git
```

2. Entre na pasta do projeto:

```bash
cd calculadora
```

3. Instale a dependência:

```bash
pip install customtkinter
```

4. Execute o programa:

```bash
python main.py
```

## Sobre o projeto

Este é um projeto de aprendizado, desenvolvido para colocar em prática conceitos de Python e explorar o desenvolvimento de aplicações com interfaces gráficas.
